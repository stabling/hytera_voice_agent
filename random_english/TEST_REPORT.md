# 随读英语 · 中文版测试报告（版本 1.3）

## 1.3 手动划词翻译专项测试

- 手动模式不运行自动网页替换。
- 选中中文后出现快捷翻译按钮；离线词典的完整词组返回对应英语。
- 允许在不含复杂元素的同一文本节点上插入英文翻译与括号原文，且原页面交互不丢失。
- 译文卡片显示翻译来源、朗读、复制、收藏以及一键撤销入口。
- 跨元素、输入区域、链接等选区不会被粗暴修改，避免破坏 DOM。
- 模拟 Chrome 内置 `Translator API` 翻译中文句子，模型不可用时不会编造译文。
- 模拟用户的兼容 AI 接口作为后备，只发送选中的中文，不额外发送整页内容。
- 总开关关闭后恢复用户手动插入过的原文。
- 增加后台菜单与快捷键消息的单元检查。
- 真实 Chrome 内置语言包下载以及实际第三方 AI 响应在当前测试环境中无法完成端到端确认。

## 1.2 版双语括号专项测试

- 默认中文替换展示：`project（项目）`，原文始终取自网页文本节点。
- 关闭设置后只展示英文；再次开启后可恢复括号中文原文。
- AI 返回已有中文括号时，统一标准化，避免双层中文括号。
- 页面原来已有同样的原文括号时，不重复显示。
- 英文网页不添加多余的英文原文括号。
- 鼠标点击与快捷提示卡片正常，单次切换“仅显示原文/恢复双语”不会丢失原文。
- 整页暂停之后，可完整还原最初 DOM 文本，不留下任何括号。
- 学习中心与弹窗都有独立开关，默认打开。

## 测试覆盖情况

- **官方简体中文配置：**扩展清单使用 `default_locale: "zh_CN"`，并提供 `_locales/zh_CN/messages.json`，浏览器显示名称与命令描述均使用中文。
- **可见文案：**已扫描插件弹窗与学习中心的界面文本；除快捷键和示例网址等不可翻译的技术标识外，文字已改为简体中文。
- **后台逻辑：**测试设置读取、智能接口调用路径、单词收藏与复习、页面内设置更改权限限制。
- **静态网页：**测试中英网页局部替换、释义卡片、发音按钮存在、生词收藏。
- **动态网页：**新增段落能够处理，原始链接与编辑框不被改造，按钮监听器保留。
- **暂停/恢复：**停用时恢复原始文案，恢复后再次改造；低强度不超过指定上限。
- **学习中心：**词库搜索、复习卡片、评分和设置保存。
- **视频字幕：**在模拟的已存在字幕 DOM 中验证中文原字幕读取、翻译叠层显示及显示模式切换。
- **离线：**不配置智能接口即可匹配本地词典、保存学习数据和复习。

## 已知局限

1. 当前沙盒浏览器受到管理员网络策略限制，**无法完成真实安装状态下的外部网页注入端到端测试**。测试采用真实 Chromium 渲染网页与模拟插件后台配合完成。
2. 没有用真实付费模型进行在线请求；实际调用需填写合法接口与密钥，接口兼容性可能有差异。
3. 视频站点可能改变字幕 DOM；有些全屏或受保护播放器无法获得普通字幕节点。
4. 英文学习素材会保留英文，这是学习功能所必需，不属于未完成的中文化。
5. 所有用户可控设置和提示均已翻译；源代码变量名、接口字段、网址和快捷键按浏览器规范保留必要的英文字符。

## 测试命令

在含 `manifest.json` 的文件夹内运行：

```text
node tests/test_core.js
node tests/test_background.js
python tests/test_browser.py
python tests/test_localization.py
python tests/test_parentheses.py
python tests/test_manual.py
```

浏览器测试需要已安装 Chromium 与 Playwright；安装插件本身不需要 Node 或 Python。
