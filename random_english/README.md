# 随读英语 · 全中文浏览器插件（版本 1.3）

**随读英语**是一款独立开发的个人无感英语学习插件。功能参考了同类英语沉浸式工具的公开说明，**不包含其他产品的内部源码或专有模型**。

这一版的**所有操作界面、菜单、按钮、设置、交互反馈、帮助说明和扩展显示名称均为简体中文**。学习时用来训练的英语单词、短语、句子会继续以英文显示；网址、编程文件名和浏览器接口名称会保留其必要形式。

## 1. 安装步骤

1. 下载 `随读英语_浏览器插件_中文版_v1.3.zip`，解压到固定目录。
2. 找到解压后的 `随读英语` 文件夹，确认它的第一层包含 `manifest.json`。
3. 打开 Chrome 的 `chrome://extensions`；Edge 用户打开 `edge://extensions`。
4. 开启“开发者模式”，选择“加载已解压的扩展程序”，**选中 `随读英语` 文件夹**。
5. 打开一篇普通中文文章，刷新页面后看到部分中文词语变成“英文（原文）”的形式，例如 `project（项目）`。若当前文章没有词库命中，可尝试包含“学习、项目、市场、数据、技术”等内容的文章。
6. 点击变更后的英文词语，查看中文解释、播放英文发音、保存生词，也可以切换为“仅显示中文原文”，或者恢复双语显示。

**从旧版升级：**若此前已经安装旧版，建议先在旧版的“隐私与帮助”中导出数据。新版继续兼容旧版备份格式，打开新版学习中心导入即可。如需保留原扩展身份，应覆盖此前加载的同一路径，不要换一个新目录加载。

## 2. 重点新增：手动划选中文，立即翻译为英文

除了原有自动无感英文化，现在也可以自己决定**哪一段中文值得学习**。

### 第一种操作：直接在网页选中中文

1. 在普通网页中用鼠标选中中文词语、短语或一小段句子。
2. 选区附近会出现按钮：**「译成英文 ↗」**。
3. 点击后会弹出中文说明的译文卡片，展示中文原文、英文译文和翻译来源。
4. 根据需要选择：**插入网页（保留原文）**、**复制英文**、**英文发音**、**收藏表达**。
5. 插入后可点击 **「撤销刚才的替换」**，也可以点击网页中的译文，再选择**「恢复这段中文」**。

示例：选择 `市场需求` → 出现 `market demand` → 点击插入 → 页面变成 `market demand（市场需求）`。

### 第二种操作：右键菜单和快捷键

- 选中中文后点击鼠标右键 → **「随读英语 · 将选中中文翻译为英文」**。
- 选中中文后按 `Alt+Shift+T`。如果快捷键被系统占用，可在 `chrome://extensions/shortcuts` 中修改。

右键菜单失去原始网页选区时仍可显示译文，但是不能安全写回原位置，因此只允许查看、复制或收藏。

### 第三种操作：完全关闭自动替换，只保留手动翻译

点击插件工具栏图标，把「网页学习模式」改成 **「只手动翻译」**。也可以在学习中心 → 偏好设置 → 网页学习方式中选择「只手动划词翻译（不自动替换）」。

手动翻译开关默认开启，可随时关闭。选择“只手动”模式时，**全局学习总开关仍需开启**。

### 中文翻译的实现方式

插件按以下顺序尝试翻译所选内容：

- **离线词典：**对完整匹配的词组立即翻译。无需网络、模型账号、密钥。
- **Chrome 内置翻译：**在支持 `Translator API` 的桌面 Chrome 中，尝试调用浏览器本机翻译模型；首次使用可能需要下载语言包。具体支持性取决于浏览器、操作系统、策略及设备情况。
- **自己配置的 AI：**如以上方式未提供译文且你开启了“智能模式”，仅将**此次手动选中的中文**发送给你配置的兼容模型接口，请求完整自然英文翻译。

这意味着不配置 API Key 时仍可翻译词典中的词组；**没有浏览器内置翻译支持的机器上，任意整句翻译需要你配置自己的模型服务**。插件不会将零散词语拼起来冒充准确的完整句子。

### 安全与格式边界

- 同一普通文字节点中、较短且选区仍有效的中文，可插入 `英文（原文）`。
- 选择横跨**多个标签、超链接、复杂排版、编辑器、代码**时，为避免破坏原页面的 DOM 或事件，可能只允许查看、复制和收藏，而不允许直接插入。
- 插入后的页面仅在本地浏览器标签中修改。刷新网页时，通常会恢复网站源文本，再根据设置重新进行自动处理。
- 在网页中暂停或关闭插件，将自动恢复插件此前改造过的普通文本。
- 内容页不会读取普通表单输入、敏感账户页或常见邮箱页面，也不记录你手动翻译的网页全文。

## 3. 既有功能：译文后保留中文原文

新版默认开启“**译文旁边保留中文原文**”，让学习时不会忘记原来的中文含义。

| 原始网页 | 开启括号原文（默认） | 关闭括号原文 |
|---|---|---|
| 项目 | project（项目） | project |
| 市场需求 | market demand（市场需求） | market demand |
| 人工智能 | artificial intelligence（人工智能） | artificial intelligence |

实际选择哪些词或短语由学习水平、接触强度和上下文决定，以上仅演示呈现形式。离线词典还增加了常见复合词组，减少逐字翻译造成的割裂感。

- **快捷开关：**点击工具栏插件图标 → 打开“译文后保留原文”。
- **详细设置：**学习中心 → 偏好设置 → “译文旁边保留中文原文”。修改后已打开的网页会重新生成标记。
- **点击标注：**可以选择“仅显示中文原文”，然后点“恢复双语显示”。
- **避免重复：**如果智能模型已经把原文放在译文括号里，不会再追加第二组；如果网页本来紧跟同样的原文括号，也不重复。
- **轻量排版：**英语使用细虚线提示，中文原文使用较浅的颜色；短语可保持同一行，较长表达允许自然换行。
- **支持英文文章：**英文原文不会再次机械地在括号里重复英文词语，英文文章继续保持原有生词标注逻辑。
- **暂停恢复：**关闭插件或暂停本页时，新增的括号和译文一起清除，原始网页正文保持原状。

## 4. 页面内功能

- **中文网页渐进式英文化：**只替换少量词汇与短语，默认以“英文（中文原文）”显示，尽可能保留原文结构。
- **英文网页学习：**在英文文章中标注已收录的重点表达，点击查看中文含义。
- **五档水平：**从入门到高级，结合词汇分层与接触比例调节。
- **显示原文：**点击已标注词语，选择“仅显示中文原文”；可暂停并恢复整页改造。
- **划词与发音：**选择网页中的英语表达查看释义，使用浏览器语音朗读。
- **词汇收藏：**保存语境、译文、熟悉状态，进入学习中心进行间隔复习。
- **动态文章：**支持部分无需刷新就能加载新正文的网站。
- **视频字幕辅助：**尝试增强油管、哔哩哔哩和奈飞的页面字幕；需要播放器把字幕绘制成可以读取的网页文本。

离线状态可使用本地词典，无需注册和登录。

## 5. 中文学习中心

学习中心包含以下页面：

- **学习概览：**累计接触词语、生词数量、待复习数量，以及最近七天的接触记录。
- **我的生词：**查找生词、听发音、标记掌握情况、移除词语。
- **间隔复习：**先回忆后揭示答案，再按自己的掌握情况选择评分。
- **偏好设置：**学习强度、语言水平、网站排除名单、智能模型接口配置。
- **隐私与帮助：**使用说明、数据备份和隐私规则。

## 6. 可选智能模式

只有配置自己的模型服务，才会发送内容进行智能处理。默认不会连接云端。

1. 进入“学习中心” → “偏好设置” → “智能语境学习”。
2. 输入兼容“聊天补全接口”的完整地址，例如 `https://api.openai.com/v1/chat/completions`。
3. 填写模型标识和接口密钥，选择“开启智能替换、语境讲解和字幕翻译”。
4. 点击“保存全部设置”，随后点击“授权模型服务地址”。
5. 点击“测试模型连接”，测试成功后刷新正在浏览的网页。

也可使用本机模型接口，例如 `http://127.0.0.1:1234/v1/chat/completions`，但需由本机模型服务实现兼容接口及跨域访问。

智能模式支持：
- 按文章语境选择更自然的英语表达与中文解释；
- 对选定词语生成简短的中文用法说明；
- 对已经存在的网页字幕尝试生成双语译文。

**注意：**模型可能产生不准确的翻译。对于敏感页面应暂停插件或禁止该网站；启用智能模式后，选定的网页片段可能传给你指定的第三方模型服务。接口费用由相应服务提供方收取。

## 7. 隐私与存储

- 默认的文字匹配、替换、生词本和复习均在本机完成，不使用开发者服务器，也不包含跟踪代码。
- 常见邮箱、登录站点、编辑框、代码区默认不处理；你也可以自行添加禁用网站。
- 启用智能模式并配置权限后，**仅必要的有限片段、字幕或选中文本**会发送到指定模型端点。
- 接口密钥保存在浏览器插件的本地存储中，**没有静态加密保证**，请只在可信的个人电脑中使用。
- 数据备份包含设置、生词、复习记录，**不包含接口密钥**。备份采用 JSON 文件，可随时导出。
- 浏览器卸载插件时可能删除其本地数据，请先备份。

## 8. 支持范围与限制

- 普通网页可改造，但不能操作 `chrome://`、浏览器扩展商店、部分跨域内嵌页面以及其他软件的窗口。
- 无法分析无文字字幕的视频；复杂视频播放器、平台 DOM 更新、全屏机制可能导致字幕增强不生效。
- 词典为独立整理的本地词库，复杂多义词需要智能模式帮助判断。
- 五档难度是启发式学习档次，而非正式的英语水平测试。
- 插件属于自用开发版本，不等同于任何商业插件的完整复刻。

## 9. 快捷键

- `Alt+Shift+L`：开启或暂停当前网页的学习；
- `Alt+Shift+E`：解释已选中的网页文字；
- `Alt+Shift+T`：手动将当前选中的中文翻译成英文。

如遇其他软件占用，可以打开 `chrome://extensions/shortcuts` 修改。

## 10. 源码说明与测试

- `manifest.json`：插件入口、权限、默认简体中文；
- `_locales/zh_CN/messages.json`：浏览器插件名称与扩展菜单中文文案；
- `scripts/dictionary.js`：离线英汉词语；
- `scripts/core.js`：词语筛选、学习水平和间隔复习算法；
- `scripts/content.js`：网页内容改造、悬浮讲解、字幕叠加；
- `scripts/background.js`：生词存储、智能接口请求；
- `ui/popup.*`：快捷设置；
- `ui/dashboard.*`：中文学习中心；
- `tests/`：算法、浏览器模拟和边界测试。

本版本经过语法检查、算法测试、括号去重、手动选区翻译与 DOM 安全性专项测试，以及 Chromium 模拟页面交互测试；由于测试环境的浏览器策略限制，**还未完成真实安装状态下、跨多个第三方站点的端到端验证**。详情见 `TEST_REPORT.md`。

这是个人使用的独立开发版本，可直接阅读、修改和离线运行。
