# FlowLingo 本地隐私说明

默认情况下，插件不会把浏览历史、网页、字幕或学习记录发送给开发者或云服务器。所有数据在 Chrome 扩展的本地存储中。

只有在用户开启 AI 开关并填写自己的 API Endpoint / Key、授予该域名访问权限后，扩展才会向所填服务发送有限的网页正文片段、字幕或选中文字，目的是提供上下文学习。第三方 API 的数据处理方式请参考对应服务政策。

扩展需要在通常的 HTTP/HTTPS 网页运行内容脚本，因此安装时浏览器可能提示它可以读取和修改你访问的网站。代码不读取密码框、编辑器或富文本输入，默认跳过常见邮箱和账户站点。你可以在设置页屏蔽更多域名。

API 密钥存入 chrome.storage.local，**它并非端到端加密的秘密保险箱**；只适合个人设备。备份导出明确不含 API Key。
