隐私与安全

LOCAL BY DEFAULT

默认词典匹配、网页替换、生词本与复习都在本地完成，数据存在 Chrome 扩展独立存储中。

只有主动启用 AI 后才向你指定的 API 服务发送有限的段落、选中文字或字幕。API Key 在本机保存，不通过网页注入。

本地扩展存储不保证静态加密；请不要在共享设备上保存敏感密钥。扩展不会主动处理输入框、代码编辑器或常见邮箱登录页面。

使用说明

GETTING STARTED
  1. 返回任意中文文章或英文资料页面，并刷新一次。
  2. 用页面右下角快捷球调整接触强度。
  3. 点击有虚线标记的单词查看语境、听发音并收藏。
  4. 在「间隔复习」中给自己的记忆打分。
  5. 有自己的大模型 API Key 时，在设置页选择开启 AI。

快捷键：Alt+Shift+L 暂停当前页，Alt+Shift+E 解释所选文字。Chrome 内置页面无法注入插件。
